# 🚀 Website Launch Checklist

A modern and interactive Website Launch Checklist tool built with HTML, CSS, and JavaScript. It helps developers ensure their website is fully ready before going live.

---

## ✨ Features

- SEO checklist
- Performance checklist
- Security checklist
- Real-time progress bar
- Clean UI design
- Responsive layout
- Beginner-friendly code

---

## 📂 Project Structure

```
website-launch-checklist/
│── index.html
│── style.css
│── app.js
│── README.md
```

---

## 🚀 How to Use

1. Open `index.html` in your browser
2. Check tasks as you complete them
3. Watch progress bar update live
4. Ensure 100% completion before launch
